# Phase 30C: plain words for the new screens (to apply after Codex run 1)

Dylan, 3 Nov 2026: the people using this aren't technical. Keep every line short, say what to do
next, and drop words like "share", "box", "calibrated", "limit" where a simpler word works. Apply
this only **after Codex finishes run 1** (changing text mid-run would break its checks), then update
the handoff's expected texts and the e2e specs, run `npm run check`, and ask Codex for a short
recheck of the changed screens.

Rules used (DESIGN.md and ui-craft): one idea per sentence; lead with what happened, then what to
do; name the button the person presses; numbers stay (16.7%, 10%); no "Not accepted/Usable" in
sentences where "rejected/OK" reads better, but the labels on badges stay as they are.
