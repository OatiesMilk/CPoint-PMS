## 1. What changed

A visual change only (D-122). No word, heading, label, role, route, API or data changed.

- **Every page:** the line under the page title is gone; the page background (and the sidebar)
  sit a step below the white cards; cards, tables and outline buttons have a softer two-layer
  shadow; in dark mode cards have a faint top light.
- **Card links** ("Open", "Edit", "Rolls", "Inventory", "Reports", the Admin home's links, the
  Operations "Open" links) are muted grey with an arrow, darker with a wash on hover.
- **Sidebar:** items 36 px tall, muted until hovered or active; the active item is dark text on
  the yellow wash with the indicator.
- **Demo mode band:** a thin line under it, regular weight. Same words.
- **Sign-in:** the Demo sign-in panel is a muted card (no dashed border) and Reset demo data sits
  below a line, apart from the accounts.
- **403 and 404:** the icon sits in a grey circle.
- **Loading and error pages** (Users, Audit log, Scans, Inventory and an item, Reports) use one
  shared skeleton and one error message style, same words.
- Form fields' outlines are a little darker (now at least 3:1 on the page too).

## 3. How to run the app locally

As in `qa/templates/handoff.md` §3, with the existing dev database (no reset needed). Restart
`npm run dev` so the CSS is rebuilt.

Existing automated tests that cover this area: the whole suite (`npm run test:e2e`), especially
`smoke.spec.ts` (axe on every page, both themes), `theme.spec.ts` and `auth.spec.ts`.
