## 1. What changed

A visual change (D-122), plus three copy changes Dylan approved (plan questions 1 to 3). No role,
route, API, label, `aria-*` or test id changed.

- **Capture, order:** the Roll card (or Start a roll), the live picture, the marker card line,
  Capture and Floor view, the Camera line, then Last scan, the roll counts card ("Today, …",
  `plan-counter`) and Model. On a wide window (`xl`) Last scan, the counts card and Model are the
  right column. Before, the counts card came first, above the Roll card.
- **Capture, phone:** the page description is hidden from view below 640 px (still read by
  screen readers), so at 390 × 844 the live picture starts on the first screen.
- **Copy 1:** "Choose the roll this shot belongs to." shows once, under the Capture button. The
  Roll dropdown's empty option reads **Choose a roll**; the line under the dropdown is gone when
  no roll is chosen.
- **Roll card:** Start another roll is a quiet (ghost) button; the roll line, the scanning timer
  and "Move the roll edge to edge…" sit together; Finish roll and Put roll back sit under a thin
  line. The card is a little tighter on a phone.
- **Under the picture:** Capture and Floor view with their help lines in one row; the Camera
  select has its own line ("Camera" beside it), 44 px tall on a phone.
- **Last scan:** the verdict sentence a step larger; the defects in a list with thin lines.
- **Floor view:** the header has the card surface, wider padding and a larger Leave button. The
  frame, the band's colours, sizes and words are unchanged.
- **Batches:** the notice banners (Batch due, Get ready, Plan today) are more compact on a phone;
  each batch card has its status badge beside "Batch N 08:00–13:00"; the batch that can be
  finished now has a ring-coloured border; the fixed bottom bar uses the card surface and a
  shadow.
- **Copy 3:** the plan line no longer repeats the interval: "Plan: 2 rolls · 128 pairs, 08:00 to
  17:00, every 4 hours. Lunch: 11:00 to 12:00." (was "… · every 4 h, 08:00 to 17:00, every 4
  hours."). The Plan days calendar still shows "every 4 h" on each day.
- The Finish batch sheet is unchanged (it already uses the 30F-1 dialog).

## 3. How to run the app locally

As in `qa/templates/handoff.md` §3, with the existing dev database (no reset). Restart
`npm run dev`. If an API route this change didn't touch answers 404, stop the server, delete
`.next\dev` and start it again. **A weekday (Monday to Friday) after 01:00 Manila** is needed for
the batch cards, the bottom bar and the Finish batch sheet; today must have a plan.

Automated tests that cover this area: `capture.spec.ts`, `capture-no-card.spec.ts`,
`batches.spec.ts`, `cv.spec.ts`, `smoke.spec.ts` (axe on every page, both themes), `auth.spec.ts`.

## 4. Test accounts and data
