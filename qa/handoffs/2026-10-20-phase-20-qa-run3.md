## 1. What changed

Run 2 passed all 14 browser scenarios. Only 4 e2e tests failed, and all 4 were test problems. No
app code changed in this round.

- `admin.spec.ts`, the temporary password and reset test: the time limit goes from 30 s to 60 s.
  In run 2 it ran out of time while signing in, under a full parallel run.
- `procurement.spec.ts`, "order, a short delivery with proof, then close short": the same change.
- `cut-around-or-clean.spec.ts`, the Settings test: it types each test key into **Find defect
  type** before checking its row, because Defect types shows 15 per page.
- `smoke.spec.ts`, the Floor Manager journey: its stock item now has a 12-character code
  (`SMK-` plus 8 digits) and `reorderLevel: 0`. Run 2 got a 422 because the code was over 20
  characters and the reorder level was missing.
