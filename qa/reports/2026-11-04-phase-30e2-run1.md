## 4. Failures

### F1 — S11 past calendar days do not open

- **Severity** Medium.
- **Steps** As Floor Manager, open Plan days, go to October, and try Oct 30. The same result occurs with `?month=2026-10&day=2026-10-30`.
- **Expected** Open a read-only day dialog with the historical plan and scan counts, as described in the handoff.
- **Actual** The cell shows 128 pairs, every 4 h and 2 rolls scanned. It is a static div with no dialog. See `src/app/(app)/batches/plan/plan-calendar.tsx:52` and `:124`. [Screenshot](artifacts/2026-11-04-phase-30e2/past-day-no-dialog.png)

### F2 — S12 Operations lacks the separate Rolls planned column

- **Severity** Medium.
- **Steps** As Floor Manager, open Reports → Operations and compare the per-day table to the Production CSV.
- **Expected** Separate Rolls planned and Rolls scanned columns in both places.
- **Actual** Operations has a Rolls scanned header. When a planned count exists, the shared table places it in that same cell. Both headers are in the CSV. See `src/components/features/production/production-parts.tsx:145` and `:173`. [Screenshot](artifacts/2026-11-04-phase-30e2/operations-production-columns.png)

### F3 — Batches e2e fails on the validation message locator

- **Severity** Medium.
- **Steps** Run the targeted Playwright command against the dev server.
- **Expected** The assertion identifies the inline rolls validation error.
- **Actual** At `tests/e2e/batches.spec.ts:168`, Playwright found two elements with the same message: the summary link and the field error. The strict-mode violation stopped the remaining six tests in the serial Batches spec. Manual S5 verified the field error and focus. [Targeted log](artifacts/2026-11-04-phase-30e2/targeted-e2e.log) · [Error context](artifacts/2026-11-04-phase-30e2/targeted-batches-error-context.md)

The same Batches strict-mode error reproduced in the full run. [Full Batches error context](artifacts/2026-11-04-phase-30e2/full-batches-error-context.md)

### F4 — Full-suite Floor Manager smoke journey timed out waiting for a toast

- **Severity** Medium.
- **Steps** Run the full suite against the dev server. The Floor Manager smoke journey updates stock and polls the toast’s opacity before the axe check.
- **Expected** Toast opacity reaches 1 before the 30-second test deadline.
- **Actual** The deadline expired at opacity 0.973436 at `tests/e2e/smoke.spec.ts:140`. The same test passed in the targeted run. [Full log](artifacts/2026-11-04-phase-30e2/full-e2e.log) · [Error context](artifacts/2026-11-04-phase-30e2/full-smoke-error-context.md)
