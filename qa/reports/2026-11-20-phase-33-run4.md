## 4. Failures

### F1 — Q14: Correction dialog remains open after saving

- **Severity:** Medium
- **Role / page:** Quality Inspector, Batches; correction dialog in the two-inspector/day-old-batch E2E scenario.
- **Steps to reproduce:** Run `tests/e2e/inspection-queue.spec.ts` in the full suite. In the two-inspector scenario, fill the correction reason and click **Save correction**.
- **Expected:** The correction dialog closes; the test then checks the updated row.
- **Actual:** `expect(fix).toBeHidden()` timed out after 10,000 ms because the dialog remained visible. The updated-row assertion was not reached.
- **Exact error:**

  ```text
  Error: expect(locator).toBeHidden() failed

  Locator:  getByRole('dialog')
  Expected: hidden
  Received: visible
  Timeout:  10000ms
  ```

- **Evidence:** [Full-suite output](artifacts/2026-11-20-phase-33-run4/e2e-full.log), [error context](artifacts/2026-11-20-phase-33-run4/e2e-full-results/inspection-queue-two-inspe-93206--day-old-batch-is-inspected-chromium/error-context.md). Failure at `tests/e2e/inspection-queue.spec.ts:246`.
- **Suggested fix:** Check the correction submit flow and dialog state after a successful save; ensure the dialog closes before the updated-row assertion.
