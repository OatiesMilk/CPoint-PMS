## 4. Failures and blocked checks

### F1 — E1.1: D-088 attendance save returned 409

- **Severity:** Medium
- **Role / page:** Floor Manager; attendance update exercised by tests/e2e/batches.spec.ts.
- **Steps to reproduce:** Run the targeted command. In the serial D-088 test, save attendance with the Quality Inspector present, then save the roster again with every Quality Inspector absent.
- **Expected:** The second save returns HTTP 200.
- **Actual:** The test received HTTP 409 at batches.spec.ts:520, called from line 547.
- **Exact error:** Error: expect(received).toBe(expected) // Object.is equality; Expected: 200; Received: 409.
- **Evidence:** artifacts/2026-11-20-phase-34-run3/targeted.log. The same D-088 test passed in the full-suite run.
- **Suggested fix:** Investigate the attendance update conflict/expectedUpdatedAt handling; unsure whether the conflict is in the fixture or application behavior.

### F2 — E1.3: total passed-pair progress did not include the repaired pair

- **Severity:** Medium
- **Role / page:** Quality Inspector; repair inspection and GET /api/v1/production/today.
- **Steps to reproduce:** Run the full suite. In the serial “the Floor Manager moves one repair and calls another not fixable; the stage marks one back; the QI inspects it” scenario, inspect the repair as passed and read today's production progress.
- **Expected:** progress.repairedPassed increases by 1 and progress.passed equals its prior value plus 1 (expected 352).
- **Actual:** The repairedPassed assertion passed, but progress.passed was 340 instead of 352.
- **Exact error:** Error: expect(received).toBe(expected) // Object.is equality; Expected: 352; Received: 340. Failure at final-defects.spec.ts:396.
- **Evidence:** artifacts/2026-11-20-phase-34-run3/full-suite.log and artifacts/2026-11-20-phase-34-run3/full-repair-failure-context.md.
- **Suggested fix:** Investigate the today-progress aggregation so its passed total matches the repaired-passed count expected by the scenario; unsure whether the intended total should be derived in the query or response mapping.

### B1 — C6: browser-console request capture unavailable

- **Severity:** Test instrumentation limitation; no severity assigned to product behavior.
- **Role / page:** Floor Manager, Demo mode band → Change time.
- **Steps:** The required window.fetch spy could not be entered because the in-app browser did not expose a browser DevTools console; Control+Shift+J did not open one. The Playwright page evaluation interface is documented as read-only, so it was not used to replace window.fetch.
- **Expected:** Read the captured request body and response status/body after setting 2026-11-20 to 17:05.
- **Actual:** Those network details were not captured. Setting the field through locator fill displayed 17:05, but the resulting band showed Demo clock: Fri, 20 Nov 2026 · 09:13 (the original prefill). Selecting the hour segment and typing 1705 by keyboard then set the band to 17:05. The clock was returned to Real time.
- **Evidence:** In-app browser showed the time input value as 17:05 before Set clock and the band as 17:05 after keyboard entry. Request body, status and response body remain unverified.
