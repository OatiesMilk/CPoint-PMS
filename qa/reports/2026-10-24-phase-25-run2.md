## 4. Failures

### F1 — R1 first run and R2: D-088 Floor Manager check-in locator matches two rows

- **Severity:** Medium
- **Role / page:** Floor Manager, `/production`
- **Steps to reproduce:** Run `npx playwright test tests/e2e/production.spec.ts --workers=1`, or run the full `npm run test:e2e` suite. The D-088 test saves a check-in with the note `E2E FM cover`, then locates a row by that static note.
- **Expected:** The locator identifies the newly entered row and contains `Entered`.
- **Actual:** Playwright reports a strict-mode violation: the locator matches two rows, `01:00 check-in` and `02:00 check-in`.
- **Evidence:** `artifacts/2026-10-24-phase-25-run2/r1-1.log`, `e2e.log`, and `e2e-d088-failure-context.md`.

  ```text
  Error: strict mode violation: getByTestId('today-check-ins').getByRole('row').filter({ hasText: 'Note: E2E FM cover' }) resolved to 2 elements:
  1) <tr aria-label="01:00 check-in">…</tr>
  2) <tr aria-label="02:00 check-in">…</tr>
  tests/e2e/production.spec.ts:277
  ```

- **App or test:** The test locator is wrong for accumulated dev test data: the static note matches old check-ins as well as the new row. Suspect `tests/e2e/production.spec.ts:269` (static note) and line 277 (row locator).

### F2 — R1 second run: color contrast violation in Schedule and quota test

- **Severity:** Medium
- **Role / page:** Floor Manager, `/production/plan`
- **Steps to reproduce:** Run the second required `npx playwright test tests/e2e/production.spec.ts --workers=1`. The schedule/quota scenario reaches its final axe check.
- **Expected:** `axe(page)` returns no violations.
- **Actual:** Axe reported one `color-contrast` violation on `li[data-index="0"] > div[data-content=""] > div[data-title=""]`.
