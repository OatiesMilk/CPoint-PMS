## 4. Failures

### F1 — S14: `send_refused` log entries omit `attempts`

- **Severity:** Low
- **Role / page:** Camera station log; command-line scenario.
- **Steps to reproduce:** 1. Run the station through refused-send cases. 2. Inspect `cv/out/logs/station-2026-10-19.jsonl` for `send_refused` events.
- **Expected:** Required event metadata includes `attempts`.
- **Actual:** Both `send_refused` entries omit `attempts`. The file otherwise has 78 valid JSON lines, all with `time`; no device token was present. Network `send_failed` entries include the `httpStatus` key, set to null when there was no HTTP response.
- **Evidence:** [`S14.log`](artifacts/2026-10-19-phase-15-camera-station/S14.log), [`S14-station-log.jsonl`](artifacts/2026-10-19-phase-15-camera-station/S14-station-log.jsonl).
- **Suggested fix:** In `cv/cpoint_cv/station.py`, include `attempts` on `send_refused` records (or narrow the handoff's required fields to the event types that use them).

### F2 — Existing Playwright spec: active `crease` does not enter unknown review

- **Severity:** Medium
- **Role / page:** Playwright e2e; Floor Manager scan detail.
- **Steps to reproduce:** 1. Run `npm run build`. 2. With the app running at port 3000, run `npx playwright test tests/e2e/cv.spec.ts`. 3. The D-028 test posts `classKey: "crease"` at confidence 0.8, then expects the detail page to say “Waiting for a Quality Inspector.”
- **Expected:** Test expects an unknown, pending-review scan and no Floor Manager decision controls.
- **Actual:** Because S4's Settings state has `crease` active, the scan is automatically decided REWORK at 80%. The expected waiting text is absent; suite result is 7 passed, 1 failed. This behavior matches the active defect-type rule; the failing test fixture no longer represents an unknown class.
- **Evidence:** [`existing-build-playwright.log`](artifacts/2026-10-19-phase-15-camera-station/existing-build-playwright.log), [`existing-e2e-cv-failure.png`](artifacts/2026-10-19-phase-15-camera-station/existing-e2e-cv-failure.png), `test-results/cv-only-a-Quality-Inspecto-6b282-Manager-only-sees-it-D-028--chromium/error-context.md`.
- **Suggested fix:** In `tests/e2e/cv.spec.ts:165`, use `sim-unknown` for the D-028 pending-review case, consistent with the Phase 15 unknown-class contract, rather than the now-active `crease` class.
