## 4. Failures

### F1 — L12: full E2E suite remains non-green

- **Severity:** High for the regression check; suite did not pass.
- **Role / page:** Multiple roles and pages on the working-tree app at port 3001.
- **Steps to reproduce:** Set `E2E_BASE_URL` to `http://localhost:3001`; run the six targeted specs listed above, then run `npm run test:e2e`.
- **Expected:** The targeted and full E2E suites pass.
- **Actual:** The targeted run passed 30/30. The full suite reported five failures:
  - `inventory.spec.ts:336`: 30-second timeout while a demo role sign-in was expected to land on `/batches`; the page observed `/login` then `/`.
  - `reports.spec.ts:80` (D-117): the expected daily-table row for `2025-08-06` was missing; the run then logged `Protocol error (Runtime.callFunctionOn): Internal server error, session closed` and timed out at 30 seconds.
  - `returns.spec.ts:121` (D-116): `AxeBuilder.analyze()` timed out at 30 seconds.
  - `rolls.spec.ts:28`: after selecting a roll, the heading remained “Reports” instead of `LR-BSA-208` until the 30-second timeout.
  - `smoke.spec.ts:151`: expected `/camera/capture`, received `/login` through the 10-second sign-in assertion.

  Each failure met the prompt's conditional rerun rule. The five spec files were run individually once. Across those file reruns, 7 tests passed and 24 failed; the failures consistently showed role sign-in remaining on `/login` or redirecting to `/`. The original full run's error contexts are under [test-results-full](artifacts/2026-11-19-phase-32-run2/test-results-full/); rerun output is under the linked individual logs and `test-results-rerun-*` directories.

- **Evidence:** [full E2E log](artifacts/2026-11-19-phase-32-run2/e2e-full.log); [individual rerun logs](artifacts/2026-11-19-phase-32-run2/).
- **Suggested fix:** Investigate role sign-in/session behavior and shared dev-server/test-data behavior under the current six-worker E2E run. No timeout or worker setting was changed for this QA run.
